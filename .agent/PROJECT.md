# tiktok-private-api — паспорт проекта

> Для агентов Manager. Создано 2026-10-19. Проверь и дополни при необходимости.

**Что это.** Тонкий Python-клиент приватного API TikTok (пакет tiktokflow) поверх ядра tiktok-private-api-core. Мобильная подпись/устройство — owner_only.
**Правила.** Ветка `agent/*` + PR, мерж — после «да» владельца. Пути из `policy.yml → owner_only` (подпись, отпечатки устройства, реверс-материалы, headless-регистрация) агенты НЕ трогают — это анти-детект-ядро владельца. Агент дорабатывает обвязку: эндпоинты поверх ядра, парсинг ответов, типы, тесты, доки, упаковку, CI.
**Реверс/починка парсинга** — задача для агента `reverser` (Opus 4.7), при отказе `reverser-max` (Opus 4.6).

## Проверка
- `python -c "import tiktokflow"` — импорт пакета
- тесты/линтер проекта, если есть (`pytest`, `ruff check`)

**CI.** manager-ci (секреты + синтаксис). GitHub Pages отключён (библиотека, сайт не нужен).
